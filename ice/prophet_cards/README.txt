WDD 130 ICE Challenge — Prophet Card

1. Copy the ice folder into the root of your existing WDD 130 repository.
2. Commit and Push origin in GitHub Desktop.
3. Open https://YOUR-USERNAME.github.io/YOUR-REPO/ice/prophet_cards/oaks.html
4. Verify the page and submit that direct URL to Canvas.

The HTML loads the exact image linked in the assignment directly from the instructor website, so no additional image download is required for it to display online. If your instructor checks for a local image file, download the starter JPG from https://andejuli.github.io/wdd130-new/ice/prophet_cards/images/dallin_oaks.jpg into ice/prophet_cards/images/, then replace the image src in the HTML with images/dallin_oaks.jpg.
